## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repo-link>
   ```

2. Open in Android Studio:

   * Launch Android Studio
   * Click **Open Project**
   * Select this repository

3. Build the project:

   * Let Gradle sync complete
   * Run the app on emulator or physical device
